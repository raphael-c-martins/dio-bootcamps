## ✨ Desafios Implementados

### 1. Análise Simples de Ações (`desafio01 -  Análise Simples de Alta, Baixa ou Estabilidade de Ações.py`)
- **Cenário:** Sistema para investidores iniciantes identificarem rapidamente se uma ação valorizou, desvalorizou ou permaneceu estável com base nos preços de abertura e fechamento.
- **Entrada:** Dois números inteiros representando os valores de abertura e fechamento.
- **Saída:** `ALTA`, `BAIXA` ou `ESTAVEL`.
- **Conceitos Aplicados:** Leitura com `input()`, separação de múltiplos valores com `.split()`, coerção de tipos para `int` e lógica condicional (`if/elif/else`).

### 2. Padronização de Nomes de Destinatários (`desafio02 -  Nome Do Destinatário Em Caixa Alta para Transferências Bancárias.py`)
- **Cenário:** Módulo de higienização de dados para transferências bancárias digitais, padronizando os nomes dos destinatários para caixa alta (*uppercase*) e evitando inconsistências em operações automatizadas.
- **Entrada:** String contendo o nome do destinatário informado pelo usuário.
- **Saída:** String com todas as letras em maiúsculas, preservando caracteres numéricos e espaçamentos.
- **Conceitos Aplicados:** Tratamento de strings e uso do método nativo `.upper()`.
