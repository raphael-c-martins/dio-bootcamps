## 📋 Sobre o Desafio

Desenvolvimento de uma **Planilha de Produtividade e Gestão de Backlog** utilizando os conceitos fundamentais do Microsoft Excel. A planilha organiza o fluxo de tarefas de uma equipe, permitindo rastrear o status de execução, responsáveis, datas de entrega e níveis de prioridade, além de conter indicadores automáticos de progresso.

## ✨ Funcionalidades

- **Controle de Backlog:** Listagem estruturada de tarefas com identificador numérico, descrição da atividade e responsável (*Owner*).
- **Acompanhamento de Status:** Classificação dos itens em `Not Initiated`, `In Progress` e `Done`.
- **Priorização de Atividades:** Escala de prioridade para direcionar o foco da equipe.
- **Métricas Automatizadas:** Fórmulas para contagem de total de atividades e atividades concluídas.

## 🛠️ Tecnologias Utilizadas

- **Microsoft Excel / OpenPyXL:** Criação, formatação de células e fórmulas de agregação.
- **Modelagem de Tarefas:** Estruturação lógica de backlog para acompanhamento de projetos.

## 🚀 Como Utilizar

1. Abra o arquivo `planilha-de-produtividade.xlsx` no Microsoft Excel, LibreOffice Calc ou Google Sheets.
2. Acompanhe ou edite as tarefas no painel de Backlog.
3. Observe a atualização automática dos indicadores no painel de métricas.
